# Portfolio — Amadou Dao

Portfolio personnel d'**Amadou Dao**, Spécialiste IT polyvalent (systèmes & réseaux, développement web, digitalisation / ICT4D, création visuelle). Basé à Bamako, Mali.

Site statique en HTML / CSS / JavaScript, sans dépendances ni étape de build.

## Sections

- **Accueil** — présentation et carte de code
- **À propos** — profil et langues
- **Compétences** — 6 catégories (Systèmes & Réseaux, Développement Web, Digitalisation & ICT4D, Graphisme & Vidéo, Bureautique & Collaboration, Support & Services IT)
- **Expérience** — parcours professionnel
- **Formation** — diplômes, certifications et centres d'intérêt
- **Réalisations** — projets clés
- **Contact** — formulaire (validation côté client) et coordonnées

## Fonctionnalités

- Thème clair / sombre (préférence sauvegardée dans `localStorage`)
- Design responsive avec menu mobile
- Animations d'apparition au défilement

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou servir le dossier :

```bash
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```

## Structure

```
.
├── index.html    # structure et contenu
├── styles.css    # styles et thèmes
└── script.js     # thème, menu mobile, animations, formulaire
```
